## 점검 항목 (id 는 c01~ 순번)
1. c01 접수: 성실한청소부 → 매칭방식 "비교선정", 단가유형 "견적요청" 오더 등록.
2. c02 지원 1: 노련한장인 → [지원하기] → 나의오더현황에 "선정대기·지원오더" 카드.
3. c03 지원자 전화/채팅: 지원 직후 오더 상세 하단에 "지원 완료·선정대기" + 전화/접수자와 채팅 버튼 노출.
4. c04 지원 2·3: 든든한기술자·용감한강아지 계정으로 각각 지원 → 접수자 상세 "지원 홈프로 (3)" 목록.
5. c05 견적가 전송: 지원자 1명이 나의오더현황 카드 [견적서 전송] → 금액 → 접수자 지원 목록에 "견적가 N원" 표시, 미전송자는 "견적가 미전송".
6. c06 선정: 접수자가 1명 [선정] → 확인 팝업 → 배정 전환 + "이미 1팀이 선정된" 중복 가드(다른 지원자 선정 시도).
7. c07 미선정 처리: 미선정 지원자 계정에서 나의오더현황 → 취소 탭에 "미선정" 표기 + 오더 상세 하단 "미선정·다른 홈프로가 선정되었습니다".
8. c08 접수자 카드: 선정 후 접수자 카드에 배정된 프로 1명만 표시(지원자 전원 아님 — 7/24 수정 회귀).
9. c09 대기 초기화: (별도 비교선정 오더에 지원 1건 받은 뒤) 접수자가 [대기] 전환 → 지원자 계정 나의오더현황에서 유령 "선정대기" 카드가 사라지는지(7/29 수정 회귀 — applicantUids 초기화).
10. c10 대기 숨김: 대기 전환된 오더가 다른 프로 메인 목록에 안 뜨는지 + URL 직접 진입 시 클릭 차단 문구(7/29 수정 회귀).

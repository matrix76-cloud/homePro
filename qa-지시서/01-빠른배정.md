## 점검 항목 (id 는 p01~ 순번)
1. p01 접수: 성실한청소부 로그인 → 예약접수 → 카테고리 "전문청소" → 홈클리닝 → 이사청소 → 필수값 채우고 매칭방식 "빠른배정", 단가유형 "시공금액 300,000원"으로 등록. 미리보기에 입력값 표시 확인.
2. p02 노출: 노련한장인 로그인 → 메인 오더목록에 방금 오더가 접수(보라 행)로 뜨는지.
3. p03 상세: 오더 클릭 → 접수 상세 정보 섹션(건물유형·옵션 등 입력값) 표시 확인.
4. p04 수락: [수락하기] → 확인 팝업 → 나의오더현황 자동 이동 → "배정·수락오더" 카드 확인.
5. p05 접수자 반영: 성실한청소부 나의오더현황 → 같은 오더 "배정" + 배정된 프로 1명 표시.
6. p06 채팅: 오더 상세 → [접수자와 채팅] → 채팅방 열림 + **입력창이 잠기지 않고 메시지 전송·수신 왕복**(7/29 잠금 해제 회귀 확인 — 핵심).
7. p07 견적서 전송: (단가유형을 "현장견적"으로 한 별도 오더를 하나 더 만들어) 수락 후 홈프로 카드의 [견적서 전송] → 금액 입력 → 접수자 카드에 "전송된 견적가" 표시 + 버튼이 1회 후 사라지는지.
8. p08 작업완료 게이트: 배정 직후 [작업완료] 클릭 → "2시간이 지나야" 안내 확인 (완료 처리는 하지 말 것 — 리뷰 카테고리 몫).
9. p09 취소요청: 홈프로 [취소요청] → 사유 선택 → 오더가 취소되고 접수자 쪽에도 취소로 보이는지.
10. p10 활동로그: 오더 상세 하단 "오더이력"에 접수→수락→(견적서)→취소 로그가 시간순으로 쌓였는지.

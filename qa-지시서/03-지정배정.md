## 점검 항목 (id 는 d01~ 순번)
1. d01 접수: 성실한청소부 → 매칭방식 "지정배정", 지정 번호 = 노련한장인 전화번호로 오더 등록.
2. d02 지정 프로 노출: 노련한장인 오더 상세 하단에 [거절하기]·[수락하기] 노출(전화번호 매칭 가드).
3. d03 비지정 차단: 든든한기술자 진입 시 "지정배정 오더 · 지정된 홈프로만 수락할 수 있습니다" 문구 + 수락/거절 버튼 없음(7/29 가드 회귀).
4. d04 거절: 노련한장인 [거절하기] → 오더 '대기' 전환(Firestore 교차) — 남의 오더 통째 대기 전환 버그의 정상 경로 확인.
5. d05 재접수→수락: 접수자 재접수 → 노련한장인 [수락하기] → 배정 전환 + 접수자 카드에 배정 프로 표시.
6. d06 한계 명시: 지정 프로 자동 매칭·알림 미구현(지정 번호는 수동 입력·프로가 목록에서 직접 진입해야 함) — 코드 근거로 확정 기록.

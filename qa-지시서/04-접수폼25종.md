## 점검 방법 (카테고리당 1행, id 는 f01~f25)
성실한청소부 로그인 → /order/create → 각 카테고리에 대해:
1. 서비스 그룹 수·이름이 config 의 subGroups 라벨과 일치하는지
2. 첫 서비스의 종목 칩들이 config items 와 일치하는지 (개수 + 앞 3개 대조)
3. 종목 1개 선택 후 나타나는 속성 섹션(attrSections)이 config 와 일치하는지
   — 특히 전문청소는 서비스별 한정(services) 확인: 홈클리닝=옵션선택만, 특수청소=오염유형·발생원인·작업범위·폐기물처리, 화재청소=피해정도, 바닥=바닥재질
4. 입력칸(inputSections·qtyPerSelected)이 있는 카테고리(폐기물·곰팡이·이사·자동차·사주·팀원기술자·가전분해·침대카페트)는 입력칸 노출·타입(숫자/글자/선택/날짜) 확인
5. 스샷 1장(속성·입력칸이 보이는 시점)
- note 에 "서비스 N·종목 N·속성 N·입력칸 유무" 요약. 불일치 발견 시 ok:false + 무엇이 다른지.

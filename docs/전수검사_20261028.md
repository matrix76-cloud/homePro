## 2. 앱 셸을 다시 빌드할 때 한 번에 넣을 것 (versionCode 3)

지금 스토어에 올라간 셸은 전부 옛 코드다. 아래는 셸 코드 수정이라 **새 빌드를 올려야 반영**된다.

- **세로 고정 없음** — `AndroidManifest.xml` MainActivity 에 `android:screenOrientation="portrait"` 빠짐 (iOS 는 세로만).
- **안드로이드 15 이상에서 웹 헤더가 상태바 밑으로 들어갈 가능성 높음** — 9/30 에 targetSdk 34 → 36 으로 올렸는데, `App.js` 가 `react-native` 의 `SafeAreaView`(iOS 전용)를 쓰고 `react-native-safe-area-context` 는 설치돼 있지 않다. targetSdk 35+ 는 강제 edge-to-edge 고 RN 0.77 코어는 인셋을 안 잡는다(opt-out 속성은 36 에서 무시). 갤럭시 S24 · S25(One UI 7+) 로 확인 필요. 처방: `react-native-safe-area-context` 설치 → `SafeAreaProvider` + 그 `SafeAreaView` 로 교체.
- **알림 채널 없음** — `MainApplication` 이 채널을 안 만들고 서버도 `channelId` 를 안 보내 FCM 기본 채널(중요도 보통)로 들어간다. 삼성에서 화면 위 띠가 안 뜨고 알림창에만 쌓일 수 있다.
- **WEB_READY 마다 권한 재요청** — 6ecb852 로 첫 번째만 요청하게 고쳤지만 미배포.
- 오프라인이면 WebView 기본 영문 오류 화면이 뜬다(`renderError` 없음).
- `android/app/google-services.json.43f7f.bak` 는 삭제된 옛 프로젝트 잔재 — 지운다.

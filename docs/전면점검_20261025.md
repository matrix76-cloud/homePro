## 2. 남은 것 (결정이 필요하거나 별도 과제)
- **보안 (D4 · D5)**: 관리자 인증이 localStorage 키 유무뿐이고, admin 컬렉션(평문 비밀번호) · payments · homepro_cash · users 를 비로그인도 쓸 수 있다. 가짜 payments 문서로 구독 · 보험 후처리를 유발할 수 있다. Firebase Auth custom claim + 규칙 잠금 + 결제 · 원장 쓰기는 서버만 — 별도 작업으로 잡아야 한다.
- **B3** 추천코드 자기 추천(새 소셜 계정마다 3,000P), **B5** 아이디 가입 회원 비밀번호 찾기 불가, **B9** 관리자 삭제 회원 재가입 무한 루프, **B17** 소셜 로그인 중 액티비티 재생성 — 서버 phoneAuth · 가입 흐름 손질 필요.
- **A5** 구버전 location 객체 오더가 실제로 남아 있는지 확인 뒤 상세 화면 보강. **A10** 지정배정이 전화번호만 저장해 지정 프로가 모를 수 있음(푸시 없음). **A11** 셀프보장등록 오더 완료 포인트 이중 · 푸시 전체 주소 노출. **A17** 보험 필수 게이트가 카드 버튼 · 현장기록에서 우회.
- **C6 · C7** 거부 등록해도 채팅은 그대로, 방 나가면 상대에게 표시 없음. **C10** 앱 설정의 알림 끄기 · 방해금지가 서버에서 무시됨. **C12** 커뮤니티 자기 글 · 댓글 수정 삭제 없음. **C14** 채팅 사진 400px 품질 0.3. **C17** 안드로이드 알림 채널 없음.
- **D6** 월 보험 가입자가 1년형 결제하면 이중 청구, **D8** 토스 승인 중복 처리(Idempotency-Key 없음), **D10 · D11** 결제 링크 취소 · 분배 관리 화면 없음, **D17** 보험대리점 해지 · 연장이 요약 미갱신.
- 서버 런타임 Node 20 은 2026-10-30 지원 종료 — Node 22 로 올려 재배포 필요(firebase-functions 6 전환 포함).

## 3. 확인 결과 (고친 빌드 기준)
